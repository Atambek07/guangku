# Как установить Графдзеркало на телефон (для тех, кто не программист)

Это пошаговая инструкция. Не нужно ничего программировать — только следовать шагам.

## Что вам понадобится

1. **Компьютер** (Windows, Mac или Linux)
2. **Телефон на Android** (любой современный, версия 5.0 и выше)
3. **USB-кабель** для подключения телефона к компьютеру
4. **USB-OTG переходник** (чтобы подключить плоттер к телефону) — небольшой шнурок, один конец в телефон, второй — в плоттер. Стоит недорого.
5. **Плоттер** (GRBL, подключается по USB)

---

## Шаг 1. Установите Android Studio на компьютер

Android Studio — это программа, которая создаёт и устанавливает приложения на телефон.

1. Зайдите на сайт: https://developer.android.com/studio
2. Нажмите кнопку **"Download Android Studio"**
3. Скачайте и установите, соглашаясь со всеми вопросами ( нажимайте "Next" / "Далее" )
4. Когда закончится установка, запустите Android Studio

---

## Шаг 2. Откройте проект на компьютере

1. В Android Studio нажмите **"Open"** (Открыть) или **"Open an existing project"**
2. Выберите папку `phone` из этого проекта (путь до неё: `guangku/phone`)
3. Подождите, пока Android Studio загрузит все potrzebные файлы (в первый раз это может занять 10–20 минут)

---

## Шаг 3. Подготовьте телефон

1. На телефоне зайдите в **Настройки → О телефоне**
2. Найдите пункт **"Номер сборки"** и нажмите на него **7 раз подряд** (появится сообщение "Вы стали разработчиком")
3. Вернитесь в **Настройки → Система → Для разработчиков**
4. Включите переключатель **"Отладка по USB"**
5. Подключите телефон к компьютеру USB-кабелем
6. На экране телефона появится вопрос *"Разрешить отладку USB?"* — поставьте галочку "Всегда доверять этому компьютеру" и нажмите **Разрешить**

---

## Шаг 4. Установите приложение на телефон

1. В Android Studio нажмите зелёную треугольную кнопку **"Run"** (или на клавиатуре `Shift + F10`)
2. В списке устройств выберите свой телефон
3. Подождите, пока aplikace соберётся и установится (в первый раз дольше)
4. На телефоне появится иконка **Графдзеркало (телефон)**

---

## Шаг 5. Подключите плоттер к телефону

1. Включите плоттер
2. Подключите плоттер к телефону через **USB-OTG переходник** (телефон → OTG → плоттер)
3. Откройте приложение **Графдзеркало (телефон)**
4. Нажмите кнопку **"Подключить плоттер (USB)"**
5. На экране телефона появится запрос *"Разрешить доступ к USB-устройству?"* — поставьте галочку "Использовать по умолчанию" и нажмите **OK**
6. Статус должен стать зелёным: **"Подключено к плоттеру"**

---

## Шаг 6. Откройте интерфейс управления

1. Нажмите кнопку **"Открыть интерфейс (127.0.0.1:8000)"**
2. Телефон откроет в браузере страницу управления плоттером
3. Теперь вы можете:
   - Загружать текст конспекта и чертежи
   - Видеть предпросмотр перед печатью
   - Нажимать **Старт / Пауза / Стоп / Домой / Нуль**
   - Двигать осями X и Y вручную
   - Опускать и поднимать ручку

> Интернет не нужен — всё работает внутри вашего телефона.

---

## Частые вопросы

| Вопрос | Ответ |
|--------|-------|
| Телефон не видит плоттер | Проверьте OTG-переходник, убедитесь что плоттер включен, попробуйте другой USB-порт |
| Приложение не устанавливается | Убедитесь что включена "Отладка по USB" и вы нажали "Разрешить" на телефоне |
| Браузер не открывает 127.0.0.1:8000 | Подождите 5–10 секунд после запуска приложения, сервер нужен время на старт |
| Нужно ли интернет | Нет, всё работает локально внутри телефона |

Если что-то не получается — пришлите скриншот ошибки, мы разберёмся.
