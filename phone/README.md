# 📱 Графдзеркало (телефон) — Android-хост для робот-плоттера

Эта папка содержит **Android-приложение**, которое превращает ваш смартфон в **полноценный хост для робота-плоттера** — без необходимости в ноутбуке или компьютере.

Плоттер подключается к телефону напрямую через **USB-OTG переходник**, а управление ведётся через встроенный веб-интерфейс (тот же самый, что и на ноутбуке), открываемый в браузере телефона по адресу `http://127.0.0.1:8000`.

## 1. Что делает это приложение

Приложение **Графдзеркало (телефон)** позволяет:

- **Подключать плоттер напрямую к телефону** через USB-OTG переходник (без ноутбука).
- **Запускать встроенный веб-сервер** на порту 8000 внутри телефона.
- **Отдавать веб-интерфейс** на русском языке (конспект, чертеж A4, управление станком, предпросмотр, настройки) в браузер того же телефона.
- **Отправлять G-code в плоттер** через USB Host API Android с контролем кольцевого буфера GRBL.
- **Управлять станком в реальном времени**: Старт / Пауза / Возобновить / Стоп / Домой / Нуль, ручное перемещение осей X/Y, тест подъёма/опускания ручки.
- **Работать полностью автономно** — интернет не требуется, всё происходит локально внутри телефона.

## 2. Аппаратные требования

| Компонент | Требование |
|-----------|-----------|
| **Телефон** | Android 5.0 (API 21) и выше |
| **Разъём на телефоне** | USB-C или micro-USB (для OTG-переходника) |
| **Переходник** | USB-OTG (USB-C/micro-USB на мужской USB-A) |
| **Плоттер** | GRBL, подключается по USB (CH340, CP2102, Arduino и т.д.) |
| **Кабель плоттера** | Обычно USB-A → USB-B или USB-A → micro-USB |
| **Питание плоттера** | 12В 1А (отдельный блок питания) |

> **Важно:** не все телефоны поддерживают USB Host (OTG). Перед покупкой проверьте specifications вашей модели — должна быть функция USB OTG.

## 5. Как работает связь с плоттером через USB-OTG

### Класс `UsbPlotter.kt`

Использует библиотеку **usb-serial-for-android** для работы с USB Host API Android.

**Что делает:**
1. Находит USB-Seial устройство (CH340, CP2102, Arduino-подобные чипы) через `UsbSerialProber`.
2. Запрашивает у пользователя разрешение на доступ к USB-устройству.
3. Открывает порт со скоростью **115200 baud** (стандарт GRBL v1.1), 8 бит, 1 стоп-бит, без чётности.
4. Ждёт 2 секунды — GRBL перезагружается при открытии порта.
5. Очищает буферы порта.
6. Запускает поток чтения ответов от GRBL (`ok`, `error`, `alarm`, `<Idle|MPos:...|WPos:...|...>`).
7. Запускает поток отправки команд с контролем `max_inflight` (не более 4 команд без подтверждения `ok`).

**Команды GRBL, которые отправляет приложение:**
| Команда | Назначение |
|---------|-----------|
| `G1 X.. Y.. F..` | Линейное перемещение со скоростью F (запись, перо вниз) |
| `G0 X.. Y.. F..` | Быстрое перемещение (перо поднято) |
| `G1 Z.. F..` | Ось Z (подъём/опускание перо) |
| `G92 X0 Y0` | Установка текущей позиции как ноля |
| `$H` | Homing (поиск нуля осей) |
| `$J=G91 X10 F1500` | Jog — относительное ручное перемещение |
| `!` | Feed hold (пауза) |
| `~` | Resume (возобновление) |
| `X` | Сброс / жёсткая остановка |
| `?` | Статус-отчёт |

## 6. Как работает встроенный веб-сервер

### Класс `WebServer.kt`

Использует библиотеку **NanoHTTPD** для создания встроенного HTTP-сервера на порту 8000.

**Что делает:**
1. Слушает порт 8000 на всех интерфейсах телефона.
2. Отдаёт HTML/JS/CSS файлы из папки `assets/www/` (копия веб-интерфейса из ноутбука).
3. Принимает запросы от браузера телефона:
   - `GET /api/serial/status` — статус подключения к плоттеру
   - `POST /api/serial/connect` — подключиться к USB-устройству
   - `POST /api/serial/disconnect` — отключиться
   - `POST /api/serial/stream` — отправить G-code на плоттер
   - `POST /api/serial/pause|resume|stop|home|zero|pen_down|pen_up` — команды станку
   - `POST /api/serial/jog` — ручное перемещение оси
   - `GET /api/fonts` — список шрифтов
   - `GET /api/presets` — пресеты разметки
   - `POST /api/layout` — разметка текста на страницы (упрощённая версия)
   - `POST /api/gcode` — генерация G-code (упрощённая версия)
4. Переводит HTTP-запросы в вызовы `UsbPlotter`.

> **Важно:** поскольку сервер работает внутри телефона, интернет не нужен. Веб-интерфейс открывается по адресу `http://127.0.0.1:8000` в браузере того же телефона.

## 7. Установка на телефон (для неподготовленного пользователя)

Полная пошаговая инструкция без терминалов и кода находится в файле **`INSTALL_PHONE_RU.md`** в этой же папке.

Кратко:
1. Установите **Android Studio** на компьютер (https://developer.android.com/studio).
2. Откройте в Android Studio папку `phone` из этого проекта.
3. Подключите телефон к компьютеру USB-кабелем.
4. На телефоне включите **Режим разработчика** (Настройки → О телефоне → 7 раз нажмите на "Номер сборки") и **Отладку по USB** (Настройки → Система → Для разработчиков).
5. В Android Studio нажмите зелёную кнопку **Run (▶)** — приложение установится на телефон.
6. Подключите плоттер к телефону через **USB-OTG переходник**.
7. Откройте приложение, нажмите **«Подключить плоттер (USB)"**, дайте разрешение на USB.
8. Нажмите **«Открыть интерфейс (127.0.0.1:8000)"** — откроется веб-интерфейс в браузере телефона.

## 9. Настройка и калибровка плоттера

Параметры плоттера (высота перо, скорости) настраиваются в коде `UsbPlotter.kt`:

```kotlin
fun penDown() => send("G1 Z-1.5 F600")   // перо вниз (пишет)
fun penUp() => send("G1 Z3.0 F600")      // перо вверх (переезд)
```

**Подбор экспериментально:**
- Если ручка не пишет — уменьшите `z_down_mm` (например, `-2.0`…`-3.0`).
- Если царапает бумагу — увеличьте `z_down_mm` (например, `-1.0`…`0`).
- Если мажет при подъёме — увеличьте `z_up_mm` (например, `4`…`6`).

**Ноль рабочей зоны:**
В веб-интерфейсе нажмите кнопку **«Нуль (G92)** — команда `G92 X0 Y0` установит текущую позицию головки как начало координат (левый верхний угол листа).

## 10. Руководство пользователя (сценарии работы)

### 10.1 Конспект в тетрадь
1. Подключите плоттер к телефону через USB-OTG.
2. Откройте приложение, нажмите **«Подключить плоттер (USB)"**.
3. Нажмите **«Открыть интерфейс (127.0.0.1:8000)"**.
4. Вкладка **«Конспект»** — вставьте текст на русском, выберите шрифт и носитель (клетка/линейка/пустой/A4).
5. Нажмите **«Разместить страницы»** → проверьте предпросмотр.
6. Нажмите **«Сформировать G-code»** → **«Отправить на станок»**.
7. Следите за прогрессом, используйте Паузу / Стоп при необходимости.

### 10.2 Чертеж на A4
1. Вкладка **«Чертеж A4»** — загрузите `.svg`-файл.
2. Нажмите **«Предпросмотр SVG»** → проверьте масштабирование под 210×297 мм.
3. Нажмите **«G-code из SVG»** → **«Отправить на станок»**.

## 11. API приложения (внутренние эндпоинты)

Базовый URL: `http://127.0.0.1:8000`.

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/api/serial/status` | Статус подключения к плоттеру |
| POST | `/api/serial/connect` | Подключение к USB-устройству |
| POST | `/api/serial/disconnect` | Отключение |
| POST | `/api/serial/stream` | Отправка G-code на плоттер |
| POST | `/api/serial/pause` | Пауза (`!`) |
| POST | `/api/serial/resume` | Возобновление (`~`) |
| POST | `/api/serial/stop` | Жёсткая остановка (`X`) |
| POST | `/api/serial/home` | Homing (`$H`) |
| POST | `/api/serial/zero` | Нуль (`G92 X0 Y0`) |
| POST | `/api/serial/jog?axis=X&mm=10` | Ручное перемещение |
| POST | `/api/serial/pen_down` | Ручка вниз |
| POST | `/api/serial/pen_up` | Ручка вверх |
| GET | `/api/fonts` | Список шрифтов |
| GET | `/api/presets` | Пресеты разметки |
| POST | `/api/layout` | Разметка текста (упрощённо) |
| POST | `/api/gcode` | Генерация G-code (упрощённо) |

## 12. Устранение типовых ошибок

| Симптом | Причина | Что делать |
|---------|---------|------------|
| Приложение не находит USB-устройство | Плоттер не подключен, не работает OTG, нет права доступа | Проверьте OTG-переходник, включите плоттер, дайте разрешение на USB в диалоге |
| Веб-сервер не запускается | Порт 8000 занят | Перезапустите приложение |
| Браузер не открывает 127.0.0.1:8000 | Сервер ещё не запустился | Подождите 5–10 секунд после запуска приложения |
| Ручка не пишет / царапает бумагу | Неправильная высота перо | Отрегулируйте `z_down_mm` / `z_up_mm` в коде UsbPlotter.kt |
| Пропускает буквы | Шрифт не содержит кириллицу | Используйте шрифт с поддержкой кириллицы |
| Приложение не устанавливается | Отладка по USB не включена | Включите Режим разработчика и Отладку по USB на телефоне |
