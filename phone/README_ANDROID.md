# Графдзеркало (телефон) — Android-хост для плоттера

Это Android-приложение, которое превращает твой телефон в **полноценный хост для робота-плоттера**:
- подключает плоттер напрямую через USB-OTG (без ноутбука),
- запускает встроенный веб-сервер на порту 8000,
- отдаёт тот же русский веб-интерфейс (разметка конспектов, чертежи A4, управление станком),
- отправляет G-code в плоттер через USB Host API.

Тебе не нужно писать на Java/Kotlin с нуля — всё уже написано. Тебе нужно только **собрать и установить приложение** через Android Studio.

## Обучение: как собрать приложение (с нуля)

### Шаг 0. Что потребуется

1. **Компьютер** (Windows, macOS или Linux) с не менее 8 ГБ ОЗУ.
2. **Android Studio** — oficialная среда разработки от Google.
   - Скачать: https://developer.android.com/studio
   - При установке выберите **Standard setup** и согласитесь установить Android SDK.
3. **Телефон на Android** (версия 5.0 / API 21 и выше).
4. **USB-OTG кабель** (USB-C или micro-USB на мужской USB-A) для подключения плоттера к телефону.
5. **Кабель USB** от плоттера (обычно USB-A → USB-B или USB-A → micro-USB).

---

### Шаг 1. Установи Android Studio

1. Скачай установщик с сайта developer.android.com/studio.
2. Запусти установку. По умолчанию всё установится в:
   - Windows: `C:\Users\<Имя>\AndroidStudioProjects\`
   - macOS: `/Applications/Android Studio.app/`
   - Linux: `~/android-studio/`
3. При первом запуске Android Studio предложит скачать **SDK Components** — согласись, это нужно.

---

### Шаг 2. Открой проект в Android Studio

1. Запусти Android Studio.
2. Нажмите **"Open"** (Открыть).
3. Выбери папку: `guangku/phone` (где лежит этот README).
4. Android Studio проиндексирует проект и скачает зависимости (usb-serial-for-android, nanohttpd). Это может занять 5–15 минут при первом запуске.

> Если Android Studio выдаст ошибку *"SDK location not found"* — настройте путь к SDK:
> `File → Project Structure → SDK Location → Укажите путь к Android SDK` (обычно `~/Android/Sdk` или `C:\Users\<Имя>\AppData\Local\Android\Sdk`).

---

### Шаг 3. Подключи телефон к компьютеру

1. На телефоне включи **Режим разработчика**:
   - `Настройки → О телефоне → Нажмите 7 раз на "Номер сборки"`.
2. Включи **Отладка по USB**:
   - `Настройки → Система → Для разработчиков → Отладка по USB`.
3. Подключи телефон к компьютеру USB-кабелем.
4. На телефоне появится запрос *"Разрешить отладку USB?"* — поставь галочку "Всегда доверять этому компьютеру" и нажмите OK.
5. В Android Studio вверху появится список устройств — выбери свой телефон.

---

### Шаг 4. Собери и установи приложение

1. В Android Studio нажмите зелёную кнопку **"Run"** (▶) или `Shift + F10`.
2. Android Studio соберёт APK и установит его на телефон.
3. На телефоне появится иконка **Графдзеркало (телефон)**.

---

### Шаг 5. Подключи плоттер к телефону

1. Включи плоттер.
2. Подключи плоттер к телефону через **USB-OTG кабель** (телефон → OTG → USB-плоттер).
3. Открой приложение **Графдзеркало (телефон)**.
4. Нажмите **"Подключить плоттер (USB)"**.
5. Система спросит *"Разрешить приложению доступ к USB-устройству?"* — поставь галочку "Использовать по умолчанию" и нажмите OK.
6. Статус станет **"Подключено к плоттеру"**.

---

### Шаг 6. Открой веб-интерфейс

1. Нажмите **"Открыть интерфейс (127.0.0.1:8000)"**.
2. Приложение откроет в браузере телефона локальный адрес `http://127.0.0.1:8000`.
3. Ты увидишь тот же интерфейс, что и на ноутбуке: вкладки Конспект / Чертеж A4 / Управление / Предпросмотр / Настройки.

> **Важно:** since сервер работает внутри твоего телефона, интернет не нужен. Всё происходит локально.

---

### Шаг 7. Печать

1. Положи лист/тетрадь, установи ноль (кнопка **Нуль / G92** в интерфейсе).
2. Загрузи текст конспекта или SVG-чертеж.
3. Нажмите **Разместить страницы** → **Сформировать G-code** → **Отправить на станок**.
4. Следи за прогрессом на экране телефона. Кнопки **Пауза / Возобновить / Стоп / Домой** работают через USB-OTG напрямую.

## Как работает код (для понимания)

### `UsbPlotter.kt`
Использует библиотеку **usb-serial-for-android** для работы с USB Host API Android. Она:
- находит USB-Seial устройство (CH340, CP2102, Arduino и т.д.),
- открывает порт со скоростью 115200 baud (стандарт GRBL),
- отправляет G-команды (`G1 X.. Y..`, `G1 Z-1.5` для перо, `$H` для домой, `!` для паузы и т.д.),
- читает ответы от GRBL (`ok`, `error`, `<Idle|...>`).

### `WebServer.kt`
Встроенный веб-сервер на базе **NanoHTTPD**:
- слушает порт 8000 на телефоне,
- отдаёт HTML/JS/CSS из `assets/www/`,
- принимает запросы от браузера (`/api/serial/connect`, `/api/serial/stream`, `/api/serial/pause` и т.д.),
- переводит их в команды UsbPlotter.

### `MainActivity.kt`
Главный экран с кнопками Подключить / Отключить / Открыть интерфейс. Запускает веб-сервер при старте.

## типовые проблемы и решение

| Проблема | Решение |
|----------|---------|
| Android Studio не видит телефон | Включи отладку по USB на телефоне, переподключи кабель, согласись на запросе доверия |
| Приложение не находит USB-устройство | Проверь OTG-кабель, убедись что плоттер включен, попробуй другой USB-порт на телефоне |
| Веб-сервер не запускается (порт занят) | Перезапусти приложение, убедись что ни другое приложение не использует порт 8000 |
| Не удалось подключиться к плоттеру | В AndroidManifest.xml укажи точный `vendorId`/`productId` своего USB-Seial чипа в `device_filter.xml` |
| Web Serial не работает в браузере | Используй встроенный интерфейс через кнопку "Открыть интерфейс", а не внешний Chrome |

## Границы текущей версии (что ещё можно доработать)

1. **Шрифты и разметка** — пока в упрощённом виде (заглушка). Полный портирование `backend/layout.py` и `backend/glyphs.py` на Kotlin — отдельная большая задача. Пока можно готовить G-code на ноутбуке и отправлять его через телефон.
2. **SVG-импорт** — упрощён. Можно доработать парсер SVG на Kotlin.
3. **Настройки перо (z_down, z_up)** — пока хардкод в `UsbPlotter.kt`, можно вынести в интерфейс.

## Если хочешь менять код

Все файлы開ты в Android Studio. Основные точки входа:
- Добавить кнопку/экран — `activity_main.xml` + `MainActivity.kt`.
- Изменить связь с плоттером — `UsbPlotter.kt`.
- Добавить API-метод — `WebServer.kt` + вызови его из `static/app.js` (в `assets/www/`).

Удачи! Если что-то не получается — пришли текст ошибки из Android Studio, разберёмся вместе.
