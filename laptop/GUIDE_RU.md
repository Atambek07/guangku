# Руководство пользователя — робот-плоттер «Графдзеркало»

Программный комплекс для автоматического письма и черчения на бумаге/тетрадях (рабочая область ~21×30 см / A4, питание 12В 1А, USB-Serial + прошивка GRBL). Весь интерфейс на русском, управление со смартфона через локальную сеть.

## 1. Инструменты и архитектура

### Какие библиотеки используются и зачем

| Инструмент | Роль в комплексе |
|---|---|
| **pyserial** | Открытие USB-Serial (`/dev/ttyUSB0`, `/dev/ttyACM0`), чтение/запись команд GRBL. |
| **fontTools** | Чтение TTF/OTF: cmap-таблица (проверка кириллицы), таблицы glyf/hmtx (контуры и avance-ширины glyph). |
| **shapely** | Геометрия при разметке/предпросмотре (площади, линии, проверка попадания в клетку). |
| **Pillow** | Рендер предпросмотра страниц в PNG. |
| **FastAPI + uvicorn + websockets** | Веб-бэкенд, REST API, WebSocket для реального времени со смартфона. |
| **python-multipart** | Приём загружаемых `.svg`-файлов. |

### Почему мы собираем свой конвейер, а не используем онлайн-конвертеры

1. **Русский рукописный шрифт без ограничений.** Онлайн-сервисы rarely поддерживают загрузку собственного рукописного .ttf с кириллицей и хорошую проверку кодировки. У нас шрифт лежит в `./fonts/`, сканируется автоматически, кириллица проверяется по cmap.
2. **Потоковая обработка любого объёма.** Конспект в hundreds страниц не загружается в память целиком — разметка идёт постранично.
3. **Предсказуемый перо.** Мы реализуем контурный обвод глифа (каждый замкнутый контур = отдельный штрих с опусканием/подъёмом перо), что для рукописных шрифтов важнее автоматической векторизации «вслепую».
4. **Управление с телефона.** Онлайн-конвертер не держит Serial-порт к GRBL, не контролирует кольцевой буфер, не делает паузу/домой/ручной ход.
5. **GRBL-специфика.** Собственный стример не переполняет incoming-буфер GRBL (~128 байт v1.1), умеет feed hold (`!`), resume (`~`), сброс (`X`), homing (`$H`), jog (`$J`).

### Архитектура

```
Смартфон (браузер, Wi-Fi) ← HTTP/WebSocket → Python бэкенд (FastAPI, 0.0.0.0:8000)
                                                     |
                                             USB-Serial (GRBL) ←→ Плоттер (X, Y, Z/перо)
```

Бэкенд содержит: сканер шрифтов, конвертер глифов, движок разметки страниц, генератор G-code, потоковый GRBL-стример с контролем буфера, очередь задач, WebSocket-хаб.

## 3. Подготовка шрифтов

### 3.1 Куда класть шрифт

Положите свой рукописный `.ttf` (или `.otf`) в папку:

```
guangku/fonts/ВашШрифт.ttf
```

После добавления нового шрифта перезапустите бэкенд (или нажмите «Перечитать конфиг/шрифты» в интерфейсе) — сканер автоматически подхватит файл.

### 3.2 Как проверить поддержку кириллицы

В интерфейсе зайдите на вкладку **Шрифты и настройки**. Для каждого шрифта показывается:

- `кириллица N/256 кодпоинтов` — сколько символов из диапазона U+0400–U+04FF есть в шрифте.
- `✓ кириллица` / `✗ неполная кириллица` — проверка набора образца `АБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯабвгдеёжзийклмнопрстуфхцчшщъыьэюя`.
- «Отсутствуют: …» — список отсутствующих букв образца.

Если в списке отсутствуют нужные буквы (например, `Ъ`, `Ё`), текст с такими буквами будет пропущен (перо не рисует, но курсор сдвигается). Замените шрифт на более полный или добавьте недостающие глифы в редакторе шрифтов (FontForge, Glyphs).

### 3.3 Настройка размера и интервала под тетрадь

Вкладка **Конспект** — поля:

- **Размер шрифта (мм)** — высота прописной буквы. Для клетки 5×5 мм подойдёт 5–7 мм, для линейки — 7–10 мм, для A4 — 9–12 мм.
- **Межстрочный интервал (мм)** — расстояние между базовыми линиями строк. Для клетки равен размеру клетки (5 мм), для линейки — 8–12 мм.
- **Интервал между буквами (мм)** — additional tracking между глифами (обычно 0.5–1.5 мм).
- **Наклон (градусы)** — наклон шрифта вправо (положительное значение) для имитации почерка.

Подбор: сделайте разметку одной страницы, посмотрите превью, отрегулируйте так, чтобы буквы попали в клетку/между линейками и не накладывались на соседние строки.

## 4. Калибровка плоттера и ручки

### 4.1 Установка нуля рабочей зоны

Ноль (0,0) — левый верхний угол листа (в конфиге `origin_corner: top-left`, Y растёт вниз по листу).

После того как плоттер с 집으로ет (или вручную переместили головку в левый верхний угол листа), установите ноль:

- В интерфейсе: кнопка **Нуль (G92)** → команда `G92 X0 Y0`.
- Или вручную через терминал GRBL: `G92 X0 Y0` (или `G10 L20 P1 X0 Y0` для постоянного сохранения).

Проверьте, что головка сейчас над левым верхним углом листа.

### 4.2 Высота и угол подъёма/прижима ручки

Параметры в `config.yaml`, секция `pen`:

```yaml
pen:
  mode: z                 # z — ось Z (типично для плоттера с сервой на Z)
  z_down_mm: -1.5         # перо касается бумаги (пишет)
  z_up_mm: 3.0            # перо поднято над бумагой (переезд)
  z_feed: 600.0           # скорость опускания/подъёма, мм/мин
```

**Как подобрать экспериментально:**

1. Поднимите головку в ноль (X0 Y0), ручку зафиксирована в держателе.
2. Опустите перо кнопкой **Ручка вниз** (команда `G1 Z{z_down}`).
3. Бумка должна касаться бумаги чётко, без провисания и без глубокого царапания.
4. Если ручка не пишет / плохо контактирует — уменьшите `z_down_mm` (опустите ниже, например -2.0…-3.0).
5. Если царапает бумагу или рвёт её — увеличьте `z_down_mm` (поднимите, например -1.0…0).
6. Если при подъёме перо мажет по бумаге — увеличьте `z_up_mm` (например 4…6 мм) или скорость `z_feed`.
7. Угол прижима регулируется механически держателем: перо должно перпендикулярно листу, без перекоса.

### 4.3 Как ровно класть тетрадь и лист A4

- Положите тетрадь/лист так, чтобы левый верхний угол совпадал с нулём станка.
- Прижмите лист скрепками или скотчом по краям, чтобы не ехал во время письма.
- Для клетчатой тетради проверьте, что линии клеток параллельны осям станка (иначе текст поплывёт относительно клетки).
- Рабочая зона по умолчанию 210×300 мм (конфиг `machine.work_width_mm`, `work_height_mm`). Лист A4 — 210×297 мм, влезает с небольшим запасом по высоте.

### 4.4 Проверка перед печатью

- Сделайте предпросмотр в интерфейсе — убедитесь, что текст попадает в поля и не выезжает за лист.
- При желании сначала прогнать G-code в режиме «перо в воздухе» (ручка поднята, `z_up`), чтобы проверить траекторию без чернил.

## 5. Установка и запуск

### 5.1 Требования

- Linux (ноутбук или одноплатник рядом с плоттером), Python 3.9+.
- Подключение плоттера к USB (зависит от чипа: `/dev/ttyUSB0` CH340/CP2102, `/dev/ttyACM0` Arduino-ориентированные).
- Права на последовательный порт: `sudo usermod -a -G dialout $USER` (после этого перелогиньтесь).

### 5.2 Пошаговая установка

```bash
cd /home/atambek/projects/guangku
bash scripts/install_deps.sh        # ставит fastapi, uvicorn, fonttools, shapely, pyserial и т.д.
```

### 5.3 Настройка порта

Отредактируйте `config.yaml`:

```yaml
serial:
  port: /dev/ttyUSB0      # или /dev/ttyACM0; пусто = режим симуляции (без железа)
  baudrate: 115200        # GRBL v1.1 по умолчанию
```

Посмотреть доступные порты можно в интерфейсе (кнопка ↻ рядом с полем порта) или командой:

```bash
python3 -m serial.tools.list_ports
```

### 5.4 Запуск

```bash
uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

Бэкенд слушает на всех интерфейсах. Если запускаете на ноутбуке — узнайте его IP (`hostname -I`).

### 5.5 Подключение смартфона

1. Смартфон и компьютер должны быть в одной Wi-Fi сети.
2. Откройте браузер на смартфоне: `http://<IP-компьютера>:8000`.
3. На вкладке **Управление станком** выберите порт и нажмите **Подключить**. Если плоттера ещё нет — оставите поле порта пустым, будет режим симуляции.

## 6. Работа с большими конспектами и чертежами A4

### 6.1 Сценарий: конспект в тетрадь (приоритет №1)

1. Положите свой рукописный `.ttf` шрифт в `./fonts/`, перезапустите бэкенд.
2. Откройте `http://<IP>:8000`, вкладка **Конспект (текст → тетрадь)**.
3. Вставьте текст конспекта на русском (любого объёма — десятки и сотни страниц обрабатываются постранично, без лимита символов).
4. Выберите носитель (клетка 5×5 мм / линейка / чистый лист / A4) и шрифт.
5. Настройте размер шрифта, межстрочный интервал, интервал букв, поля, красную строку.
6. Нажмите **Разместить страницы** — появится предпросмотр всех страниц, количество страниц, примерно время печати.
7. Проверьте превью: текст попадает в клетки/между линий, нет наложений. При необходимости подправьте параметры и повторите разметку.
8. Нажмите **Сформировать G-code** — файл сохраняется в `gcode/`.
9. Подключите станок (вкладка Управление), нажмите **Нуль** (G92) в левом верхнем углу листа, опустите перо тестовой кнопкой.
10. Нажмите **Отправить на станок** — начнётся потоковая печать с контролем буфера. На экране — прогресс, кнопки Пауза / Возобновить / Стоп / Домой.
11. По окончании страницы смените лист/тетрадь, снова поставьте ноль и продолжите со следующей страницы.

### 6.2 Сценарий: чертеж на листе A4 (приоритет №2)

1. Вкладка **Чертеж A4 (SVG)** — загрузите `.svg`-файл чертежа.
2. Нажмите **Предпросмотр SVG** — убедитесь, что чертеж масштабируется под A4 (210×297 мм) с сохранением пропорций.
3. Нажмите **G-code из SVG** — формируется G-code.
4. Положите лист A4, поставьте ноль в левом верхнем углу листа.
5. Нажмите **Отправить на станок**, настройте скорость черчения (в конфиге `feed.write` / `feed.travel`).

### 6.3 Потоковая печать и контроль буфера GRBL

G-code отправляется не одной пачкой, а по мере освобождения кольцевого буфера GRBL (не более `serial.max_inflight` команд без подтверждения `ok`). Это гарантирует, что буфер не переполнится и соединение не зависнет при печати сотен страниц.

## 7. Устранение типовых ошибок

| Симптом | Причина | Что делать |
|---|---|---|
| **Ручка не пишет / плохой контакт** | `z_down_mm` слишком мало (перо не касается бумаги) или засохший стержень | Уменьшите `z_down_mm` в config.yaml, проверьте стержень, прижмите держатель |
| **Ручка машет / царапает бумагу** | `z_down_mm` слишком много или перо не перпендикулярно | Увеличьте `z_down_mm`, отрегулируйте угол держателя |
| **Пропускает буквы** | Нет глифа в шрифте (неполная кириллица) | Проверьте вкладку Шрифты — отсутствующие буквы; замените шрифт |
| **Поехал наклон / текст не по строкам** | Лист лежит криво или неверно выставлен ноль | Ровно положите лист, проверьте параллельность клеток осям, переставьте ноль (G92) |
| **Координаты сбились** | Пропуск шагов, случайный сброс | Не трогайте головку во время печати; после сброса заново делайте Ноль (G92) |
| **Не находится /dev/ttyUSB0 или /dev/ttyACM0** | Плоттер не подключен, другой порт, нет прав | Проверьте кабель, `ls /dev/ttyUSB* /dev/ttyACM*`, права dialout, выберите верный порт в интерфейсе |
| **Обрыв связи / буфер GRBL переполнен** | Слишком быстрая отправка без ожидания `ok` | Уменьшите `serial.max_inflight` в config.yaml (по умолчанию 4); используйте кнопку Стоп и перезапустите отправку |
| **Пауза не работает / безопасная остановка** | GRBL не в состоянии Hold | Нажмите Пауза (`!`), затем Возобновить (`~`) или Стоп (`X` — полный сброс). После Стопа заново ноль через G92 |
| **Шрифты не отображаются в интерфейсе** | Файл не .ttf/.otf, битый шрифт, не перезапущен бэкенд | Положите шрифт в `./fonts/`, проверьте через сканер, перезапустите uvicorn |

### Аварийная остановка

Нажмите **Стоп (X)** — GRBL сбрасывается, очередь команд очищается, перо поднимается. После этого обязательно переустановите ноль (`G92 X0 Y0` / кнопка **Нуль**) перед следующим запуском.

## 8. HTTP API и WebSocket (кратко)

Базовый URL: `http://<хост>:8000`.

**REST:**
- `GET /api/fonts` — список шрифтов с проверкой кириллицы.
- `GET /api/presets` — пресеты разметки.
- `POST /api/layout` — разметка текста на страницы (возвращает страницы, штрихи, SVG-превью, страницы, время).
- `POST /api/gcode` — генерация G-code из страниц.
- `POST /api/svg` — загрузка `.svg` → штрихи.
- `GET /api/serial/ports` — доступные COM-порты.
- `POST /api/serial/connect | /disconnect | /status` — управление соединением.
- `POST /api/serial/stream` — потоковая отправка G-code.
- `POST /api/serial/pause | /resume | /stop | /home | /zero | /jog | /pen_down | /pen_up` — команды станку.

**WebSocket:** `WS /ws` — команды `{type: start|pause|resume|stop|home|zero|jog|pen_down|pen_up|connect|disconnect|get_status}` и рассылка статуса `{type: status, state, progress, message, line, total}`.

Веб-интерфейс (статика): `GET /` — индекс с вкладками Конспект / Чертеж A4 / Управление / Предпросмотр / Настройки, полностью на русском, адаптивный под смартфон.

---

Готово к эксплуатации: кладите шрифт в `./fonts/`, правите `config.yaml`, запускаете `uvicorn backend.main:app` и управляете плоттером со смартфона.
